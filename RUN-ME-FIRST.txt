====================================
 CivicProof — how to run (simple!)
====================================

Needs: Python 3.10+  (https://www.python.org/downloads/)

   STEP 1 — unzip this folder
   STEP 2 — run the app:
              Windows:   double-click  start.bat
              Mac/Linux: open terminal here, type  ./start.sh
   STEP 3 — open in browser:  http://localhost:8000

That's it. The demo data is already included.

---------------------------------------------
Prefer doing it by hand? Two commands:
   pip install -r requirements.txt
   python app.py
---------------------------------------------

WHAT TO CLICK FIRST:
  Home            -> live map of Chennai issues
  Explore         -> browse / upvote tickets
  CP-26-0006      -> ProofWatch caught a FAKE repair
  Authority       -> console, analytics, live verification

Port busy?  PORT=8080 python app.py   (Windows: set PORT=8080)
Reset demo? Ctrl+C, then:  python seed.py
Questions: see README.md
